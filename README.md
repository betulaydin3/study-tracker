# Study Tracker

A personal web application for organizing study tasks, tracking study sessions, and monitoring learning progress.

## About

Study Tracker is a personal software engineering project built to practice web development while creating a useful study tool.

The goal is to help students plan their work, stay organized, and understand how they spend their study time.

## Planned Features

- **Task management:** Add, view, complete, and delete study tasks.
- **Study timer:** Start and stop study sessions.
- **Dashboard:** See an overview of tasks and study activity.
- **Progress tracking:** View completed tasks and study statistics.
- **Local storage:** Save tasks and study data in the browser.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Figma (UI design and wireframes)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/betulaydin3/study-tracker.git
   ```
2. Open the project folder:
   ```bash
   cd study-tracker
   ```
3. Open `index.html` in your browser.

No additional dependencies are required for the initial version.
